# 1.Chain

## 1.1.大模型链LLMChain

```python
prompt = ChatPromptTemplate.from_template("{query}")
chain = LLMChain(prompt=prompt, llm=chat_llm)
# chain类的5种运行方式
print(chain("你是谁"))
print(chain.run("你是谁"))
print(chain.apply([{"query": "你是谁"}]))
print(chain.generate([{"query": "你是谁"}]))
print(chain.predict(query="你是谁"))
# runnable的invoke运行方法
print(chain.invoke({"query": "你是谁"}))
```

## 1.2.对话链ConversationChain

```python
chain = ConversationChain(llm=chat_llm)  # 自带记忆组件

# 第一轮对话
content = chain.invoke({"input": "你好，我是小z，我喜欢打球+游泳，你喜欢什么呢？"})
print(content)

# 第二轮对话（基于上下文）
content = chain.invoke({"input": "请统计一下我的爱好有什么"})
print(content)
```

## 1.3.文档对话链create_stuff_documents_chain

```python
# 1. 创建提示模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个强大的聊天机器人，能根据用户提供的上下文来回复用户的问题。\n\n<context>{context}</context>"),
    ("human", "{query}")
])

# 2. 创建链应用
chain = create_stuff_documents_chain(prompt=prompt, llm=chat_llm)

# 3. 文档列表
documents = [
    Document(page_content="小明喜欢绿色，但不喜欢黄色"),
    Document(page_content="小王喜欢粉色，也有一点喜欢红色"),
    Document(page_content="小泽喜欢蓝色，但更喜欢青色")
]

# 4. 调用链
out = chain.invoke({
    "query": "请帮我统计一下大家都喜欢什么颜色",
    "context": documents
})
print(out)
```
