# 2.记忆管理memory



在 LangChain 的 `BaseChatMemory` 组件中，不同的属性与方法有不同的作用：

1. `chat_memory`：用于管理记忆中的历史消息对话。
2. `output_key`：定义 AI 内容输出键。
3. `input_key`：定义 Human 内容输入键。
4. `return_messages`：`load_memory_variables` 函数是否返回消息列表，默认为 False 代表返回字符串。
5. `save_context`：存储上下文到记忆组件中（存储消息对话）。
6. `load_memory_variables`：生成加载到链的记忆字典信息。
7. `clear`：清除记忆中的对话消息历史。

![061memory](/Users/zoe/Desktop/langchain/imgs/061memory.png)



## 2.1.缓冲记忆组件

ConversationBufferMemory缓冲记忆，将所有对话信息全部存储作为记忆。

ConversationBufferWindowMemory缓冲窗口记忆，设置k值，保留2*k的对话信息作为历史信息。

ConversationTokenBufferMemory令牌缓冲记忆，设置max_token_limits。

ConversationStringBufferMemory字符串缓冲记忆，返回字符串。

```python
from operator import itemgetter

from langchain_classic.memory import ConversationBufferWindowMemory
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables import RunnablePassthrough, RunnableLambda
from langchain_ollama import OllamaLLM

# ConversationBufferWindowMemory
llm = OllamaLLM(model="qwen2.5:7b")
# 创造缓冲记忆,ConversationBufferMemory,ConversationTokenBufferMemory
memory = ConversationBufferWindowMemory(k=2, return_messages=True, input_key="query")
# 1. 构建提示模板与大语言模型
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个强大的聊天机器人，请根据用户的需求回复问题。"),
    MessagesPlaceholder("history"),  # 占位符，将自动填充历史消息
    ("human", "{query}"),
])

count_token = llm.get_num_tokens("你好呀")  #计算token值
print(count_token)
chain = RunnablePassthrough.assign(
    history=RunnableLambda(memory.load_memory_variables) | itemgetter("history")) | prompt | llm | StrOutputParser()
while True:
    # 4. 获取用户的输入
    query = input("Human: ")

    if query == "q":
        break

    # 5. 运行链并传递配置信息
    response = chain.stream(
        input={"query": query}
    )
    output = ""
    print("AI: ", flush=True, end="")
    for chunk in response:
        output += chunk
        print(chunk, flush=True, end="")
    memory.save_context({"query": query}, {"output": output})
    print("history: ", memory.load_memory_variables({}))
```

## 2.2.摘要记忆组件

ConversationSummaryMemory摘要总结记忆，将历史对话总结成摘要进行保存。

ConversationSummaryBufferMemory摘要缓冲混合记忆，超过max_token_limit限制的部分进行信息总结。

```python
from operator import itemgetter

from langchain_classic.memory import ConversationSummaryBufferMemory
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables import RunnablePassthrough, RunnableLambda
from langchain_ollama import OllamaLLM

# ConversationSummaryMemory
llm = OllamaLLM(model="qwen2.5:7b")
# 创造记忆，超过限度就摘要，摘要内容和缓冲内容摘要后替换到system
memory = ConversationSummaryBufferMemory(max_token_limit=200, return_messages=True, input_key="query", llm=llm)

# 1. 构建提示模板与大语言模型
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个强大的聊天机器人，请根据用户的需求回复问题。"),
    MessagesPlaceholder("history"),  # 占位符，将自动填充历史消息
    ("human", "{query}"),
])

chain = RunnablePassthrough.assign(
    history=RunnableLambda(memory.load_memory_variables) | itemgetter("history")) | prompt | llm | StrOutputParser()
while True:
    # 4. 获取用户的输入
    query = input("Human: ")

    if query == "q":
        break

    # 5. 运行链并传递配置信息
    response = chain.stream(
        input={"query": query}
    )
    output = ""
    print("AI: ", flush=True, end="")
    for chunk in response:
        output += chunk
        print(chunk, flush=True, end="")
    memory.save_context({"query": query}, {"output": output})
    print("history: ", memory.load_memory_variables({}))
```



## 2.3.实体记忆

```python
from dotenv import load_dotenv
from langchain_classic.chains.conversation.base import ConversationChain
from langchain_classic.memory import ConversationEntityMemory
from langchain_classic.memory.prompt import ENTITY_MEMORY_CONVERSATION_TEMPLATE
from langchain_ollama import ChatOllama

load_dotenv()

# 初始化 LLM（使用 OpenAI 的 gpt-4o 模型）
llm = ChatOllama(model="qwen2.5:7b")

# 创建对话链，启用实体记忆
chain = ConversationChain(
    llm=llm,
    prompt=ENTITY_MEMORY_CONVERSATION_TEMPLATE,  # 假设已定义模板
    memory=ConversationEntityMemory(llm=llm),
)

# 发送多轮对话
print(chain.invoke({"input": "你好，我是小z"}))
print(chain.invoke({"input": "我最喜欢的编程语言是 Python。"}))
print(chain.invoke({"input": "我喜欢吃的蔬菜是茄子"}))

# 查询实体中的对话记录
res = chain.memory.entity_store.store
print(res)
```
