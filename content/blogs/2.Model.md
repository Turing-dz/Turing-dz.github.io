# 1.ChatXXX模型实例化(langchain_xxx)

LangChain本身不提供自己的LLM，而是提供标准接口。

LLM使用纯文本作为输入输出的大语言模型。

ChatModel使用聊天消息列表作为输入并返回聊天消息的聊天模型。

两种模型接口都接受字符串，PromptValue以及消息列表作为参数，内部会根据模型的类型自动转换成字符串或者消息列表，屏蔽了不同模型的差异。

## 1.1.ChatOpenAI

```python
dotenv.load_dotenv()
chat_model = ChatOpenAI(model="gpt-3.5-turbo", base_url=os.getenv("OPENAI_API_BASE"))
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是人工智能助手，你的名字叫做小z"),
    ("human", "{query}")
])
response = chat_model.invoke(prompt.invoke({"query": "你是谁"}))
```

# 2.模型invoke，stream，batch三种运行方式

Invoke:传递对应的文本提示，消息提示，大语言模型生成对应的内容。

```python
# 1.invoke
response = chat_model.invoke(prompt.invoke({"query": "你是谁"}))
# response.__class__
response.content
```

stream：invoke的流失输出版本，大语言模型每生成一个字符就返回一个字符。

```python
# 2.stream
response2 = chat_model.stream(prompt.invoke({"query": "你是谁"}))
for chunk in response2:
    print(chunk.content, flush=True, end="")
```

batch：invoke的批量版本，可以一次行生成多个内容。

```python
# 3.batch
responses = chat_model.batch([
    prompt.invoke({"query": "你是谁"}),
    prompt.invoke({"query": "讲个笑话"}),
])
for response in responses:
    print(response.content)
    print("**" * 5)
```

# 3.模型多模态

LangChain的消息组件Message有5种类型（SystemMessage,HumanMessage,AIMessage,FunctionMessage,ToolMessage），并且所有的消息都具有type类型，content内容和response_metadata响应元数据。

## 3.1.多模态输入

```python
import dotenv
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

dotenv.load_dotenv()

# 1. 创建支持多模态（文本+图片）的提示模板
prompt = ChatPromptTemplate.from_messages([
    ("human", [
        {"type": "text", "text": "简单描述上传的图片"},
        {"type": "image_url", "image_url": "{image_url}"}  # 图片 URL 占位符
    ])
])

llm = ChatOpenAI(model="gpt-4o")
chain = prompt | llm | StrOutputParser()

print(chain.invoke({
    "image_url": "https://upload.wikimedia.org/wikipedia/commons/7/79/Canton_tower_in_asian_games_opening_ceremony.jpg"}))
```

## 3.2.多模态输出

```python
import dotenv
from langchain_community.tools.openai_dalle_image_generation import OpenAIDALLEImageGenerationTool
from langchain_community.utilities.dalle_image_generator import DallEAPIWrapper
from langchain_openai import ChatOpenAI

# 加载环境变量（如 OpenAI API Key）
dotenv.load_dotenv()

# 创建 DALL·E 图像生成工具
dalle = OpenAIDALLEImageGenerationTool(
    name="openai_dalle",
    api_wrapper=DallEAPIWrapper(model="dall-e-3")
)

# 初始化语言模型
llm = ChatOpenAI(model="gpt-4o")

# 绑定工具到 LLM（强制使用 DALL·E 工具）
llm_with_tools = llm.bind_tools(tools=[dalle], tool_choice="openai_dalle")

# 构建链：LLM → 提取工具调用参数 → 执行 DALL·E
chain = llm_with_tools | (lambda msg: msg.tool_calls[0]["args"]) | dalle

# 调用链生成图像
print(chain.invoke("帮我绘制一幅两岁中国小女孩儿当医生的可爱图片"))
```
