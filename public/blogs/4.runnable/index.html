4.Runnable

Zoe | Dec 17, 2025 min read

参考：https://reference.langchain.com/python/langchain-core/runnables

LangChain中绝大部分组件实现了Runnable协议执行接口，定义了一套标准方法。

stream：将组件的响应块流式返回，如果组件不支持流式则会直接输出。astream（异步版本）

invoke：调用组件并得到对应的结果。ainvoke（异步版本）

batch：批量调用组件并得到对应的结果。abatch（异步版本）

astream_log：除了流失返回最终响应块之外，还会流式返回中间步骤。

LangChain重写了__or__和__ror__方法，因此所有Runnable组件都可以通过｜或者pipe()方法将多个组件拼成链运行。

实现 Runnable 接口组件的输入和输出类型因组件而异，如下

组件 输入类型 输出类型
Prompt Dict PromptValue
ChatModel String,PromptValue,MessageList ChatMessage
LLM String,PromptValue,MessageList String
OutputParser LLM/ChatModel的输出 取决于解析器
Retriever String List of Document文档列表
Tool String,Dict,取决于工具所需输入 取决于工具规定输出

大部分runnable组件继承了RunnableSerializable，而RunnableSerializable继承自 Runnable，又增加了可序列化能力，支持保存为 JSON，支持 LangSmith 记录，支持远程部署，支持 graph 导出。

1.常见的Runnable实现

1.1.串行RunnableSequence

串联多个 Runnable，前一个的输出是后一个的输入

prompt = ChatPromptTemplate.from_template("讲个{topic}相关的笑话")
chain = RunnableSequence(prompt, chat_llm, StrOutputParser())# chain = prompt | chat_llm | StrOutputParser()

1.2.并行RunnableParallel

并行执行多个 Runnable，将结果组合为字典。

prompt_joke = ChatPromptTemplate.from_template("写一个{subject}相关的笑话")
prompt_poem = ChatPromptTemplate.from_template("写一个{subject}相关的诗")
chain_joke = prompt_joke | chat_llm | StrOutputParser()
chain_poem = prompt_poem | chat_llm | StrOutputParser()
# chains = RunnableParallel({"joke": chain_joke, "poem": chain_poem})
chains = RunnableParallel(joke=chain_joke, poem=chain_poem)
res = chains.invoke({"subject": "天气"})

1.3.RunnableLambda把函数包装成 Runnable

# 将任意 Python 函数封装为 Runnable。适用场景：插入自定义逻辑（如数据清洗、格式转换）。
def retrieval(query: str) -> str:
    """模拟检索器"""
    print("正在检索...")
    return "我是小z"


prompt = ChatPromptTemplate.from_template("""参考上下文内容回答用户问题

<context>
{context}
</context>

用户问题是：{query}
""")
query = "我是谁"
runnable_retrieval = RunnableLambda(
    lambda x: {
        "context": retrieval(x["query"]),
        "query": x["query"],
    }
)
chain = runnable_retrieval | prompt | chat_llm | StrOutputParser()
res = chain.invoke({"query": query})

1.5.分支执行RunnableBranch

# 根据条件选择执行不同的分支。适用场景：动态路由（如根据输入类型选择不同处理路径）。
prompt_coder = ChatPromptTemplate.from_template("写一个程序员相关的{subject}的诗")
prompt_boss = ChatPromptTemplate.from_template("写一个老板相关的{subject}的诗")
prompt_free = ChatPromptTemplate.from_template("写一个躺平相关的{subject}的诗")

chain_coder = prompt_coder | chat_llm | StrOutputParser()
chain_boss = prompt_boss | chat_llm | StrOutputParser()
chain_free = prompt_free | chat_llm | StrOutputParser()
branch = RunnableBranch(
    (lambda x: "bug" in x.get("subject", ""), chain_coder),
    (lambda x: "开会" in x.get("subject", ""), chain_boss),
    chain_free
)
print(branch.invoke({"subject": "天天写bug"}))
print("==" * 20)
print(branch.invoke({"subject": "天天开会"}))
print("==" * 20)
print(branch.invoke({"subject": "睡大觉"}))

1.6.多轮对话 RunnableWithMessageHistory

# 为链添加对话历史管理。适用场景：聊天机器人、多轮对话。
# 会话历史存储字典（用于缓存）
store = {}
def get_session_history(session_id: str) -> BaseChatMessageHistory:
    if session_id not in store:
        # 创建文件存储的聊天历史对象
        store[session_id] = FileChatMessageHistory(f"./chat_history_{session_id}.txt")
    return store[session_id]

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个强大的聊天机器人，请根据用户的需求回复问题。"),
    MessagesPlaceholder("history"),
    ("human", "{query}"),
])

chain = prompt | chat_llm | StrOutputParser()
with_message_chain = RunnableWithMessageHistory(chain, get_session_history, input_messages_key="query",
                                                history_messages_key="history")
while True:
    query = input("Human: ")
    print(query)
    if query == "quite":
        break
    else:
        response = with_message_chain.stream(
            input={"query": query},
            config={"configurable": {"session_id": "z"}}
        )

        print("AI: ", flush=True, end="")
        for chunk in response:
            print(chunk, flush=True, end="")
        print("")

2.Runnable组件常用方法

2.1.提前绑定参数bind

bind函数用于修改Runnable底层的默认调用参数。

.bind() 函数是在构建应用的时候添加上对应的默认调用参数，而在 Runnable.bind() 函数的底层，本质上是往 Runnable 的 kwargs 属性添加对应的字段，并生成一个新的 Runnable，当 Runnable 组件执行调用时（invoke、ainvoke、stream、astream、batch、abatch 等），会自动将 kwargs 字段里的所有参数合并并覆盖默认调用参数。

bind函数只能绑定运行时参数。

# 如果要将一个函数编程runnable组件，可以通过runnablelambda函数进行包装，所有的runnable组件的invoke函数智能传递一个参数，类型不限。所以如果想要传递多个参数，就用bind方法。
def get_weather(location: str, unit: str) -> str:
    # print(location, unit)
    return f"{location}的天气为{random.randint(24, 40)}{unit}"


# bind方法其实就是吧bind的参数进行了绑定并生成一个新的runnable组件
get_weather_runnable = RunnableLambda(get_weather).bind(unit="度")  # 自定义函数变成一个runnable组件
print(get_weather_runnable.kwargs)
resp = get_weather_runnable.invoke("北京")

2.2.invoke时通过with_config绑定参数configurable_fields

# 1.先使用ConfigurableField在runnable上规定哪个参数是在运行时要传递的
prompt = ChatPromptTemplate.from_template("生成一个小于{x}的随机数")
llm = chat_llm.configurable_fields(
    temperature=ConfigurableField(
        id="llm_temperature",
        name="模型温度值",
        description='温度越低随机性越低'
    )
)
chain = prompt | llm | StrOutputParser()
res = chain.invoke({"x": 100})
print(res)
print("****" * 10)
# 2.runnable在invoke的时候通过config传递configurable值（字典，键是第一步定义的id）
# res = chain.invoke({"x": 100}, config={"configurable": {"llm_temperature": 0}})
# 2.在 Runnable 的 invoke 或 ainvoke 方法中显式接收 config 参数，并在内部逻辑中解析和应用配置。
# res = chain.invoke({"x": 100}, config=RunnableConfig(configurable={"llm_temperature": 0}))
# 2.runnable的with_config方法进行配置
res = chain.with_config({"configurable": {"llm_temperature": 0}}).invoke({"x": 100})
print(res)

2.3.invoke时改变配置configurable_alternatives

prompt = ChatPromptTemplate.from_template("{query}")
# 1.对runnable组件进行configurable_alternatives替换配置,要配置唯一的id,然后配置新runnable，第二步用到id和runnable的名字
llm = chat_llm.configurable_alternatives(
    ConfigurableField(id="llm"), llm3=ChatOllama(model="llama3"))
chain = prompt | llm | StrOutputParser()
# 2.运行时config传递改的runnable
res = chain.invoke({"query": "你是哪个模型"}, config={"configurable": {"llm": "llm3"}})

2.4.绑定容错机制-重试with_retry和回退with_fallbacks

a = 1
def foo(x):
    global a
    x = a + x
    a += 1
    print(x)
    return 5 / x

chain = RunnableLambda(foo).with_retry(stop_after_attempt=2)
res = chain.invoke(-1)
print(res)

prompt = ChatPromptTemplate.from_template("{query}")
llm = ChatOllama(model="qwen2.5:8b").with_fallbacks([ChatOllama(model="qwen2.5:7b")])
chain = prompt | llm | StrOutputParser()
res = chain.invoke({"query": "你是谁"})
print(res)

2.5.周期回调callbacks

事件名称 触发时机 对应回调函数
LLM start 当大语言模型启动时 on_llm_start
LLM new token 当聊天模型或大语言模型生成新 token 时 on_llm_new_token
LLM end 当聊天模型或大语言模型结束时 on_llm_end
LLM error 当聊天模型或大语言模型发生错误时 on_llm_error
Chain start 当链开始运行时 on_chain_start
Chain end 当链结束时 on_chain_end
Chain error 当链发生错误时 on_chain_error
Tool start 当工具开始运行时 on_tool_start
Tool end 当工具结束时 on_tool_end

使用回调的三种方式 chain.invoke(input, config={“callbacks”: [callback_handler]})在运行 invoke 时传递对应的 config 信息配置 callbacks（推荐） chain = chain.with_config({“callbacks”: [callback_handler]})在 Chain 上调用 with_config 函数，传递对应的 config 并配置 callbacks（推荐） llm = OpenAI(callbacks=[callback_handler])在构建大语言模型时，传递 callbacks 参数 LangChain 提供的两个基础 CallbackHandler： stdoutCallbackHandler：将日志输出到标准输出（控制台） FileCallbackHandler：将日志写入文件，便于调试和记录

prompt = ChatPromptTemplate.from_template("{query}")

parser = StrOutputParser()
query = "我是谁"
chain = {"query": RunnablePassthrough()} | prompt | chat_llm | parser


# res = chain.invoke(query, config={"callbacks": [StdOutCallbackHandler()]})
class LLMOpsCallbackHandler(BaseCallbackHandler):  #自定义callbackhandler
    """自定义回调处理器"""
    start_at: float = 0

    def on_chat_model_start(
            self,
            serialized: dict[str, Any],
            messages: list[list[BaseMessage]],
            *,
            run_id: UUID,
            parent_run_id: UUID | None = None,
            tags: list[str] | None = None,
            metadata: dict[str, Any] | None = None,
            **kwargs: Any,
    ) -> Any:
        print("聊天模型开始了...")
        print("serialized:", serialized)
        print("messages:", messages)
        self.start_at = time.time()

    def on_llm_end(
            self,
            response: LLMResult,
            *,
            run_id: UUID,
            parent_run_id: UUID | None = None,
            **kwargs: Any,
    ) -> Any:
        end_at = time.time()
        print("模型生成：", response)
        print("模型生成耗时：", end_at - self.start_at)

    def on_llm_new_token(
            self,
            token: str,
            *,
            chunk: GenerationChunk | ChatGenerationChunk | None = None,
            run_id: UUID,
            parent_run_id: UUID | None = None,
            **kwargs: Any,
    ) -> Any:
        print("token生成了...")
        print("tiken:", token)


res = chain.invoke(query, config={"callbacks": [StdOutCallbackHandler(), LLMOpsCallbackHandler()]})
print(res)

2.6.带异常信息回调并重新生成

from typing import Dict, Any

from langchain_core.messages import AIMessage, ToolMessage, HumanMessage
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableConfig
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI


# 自定义异常类：用于封装工具调用失败的信息
class CustomToolException(Exception):
    def __init__(self, tool_call: "ToolCall", exception: Exception) -> None:
        super().__init__()
        self.tool_call = tool_call
        self.exception = exception


@tool
def complex_tool(int_arg: int, float_arg: float, dict_arg: dict) -> int:
    """使用复杂工具进行复杂计算操作"""
    return int_arg * float_arg


def tool_custom_exception(msg: AIMessage, config: RunnableConfig) -> Any:
    """
    尝试执行工具，如果失败则抛出自定义异常。
    """
    try:
        return complex_tool.invoke(msg.tool_calls[0]["args"], config=config)
    except Exception as e:
        raise CustomToolException(tool_call=msg.tool_calls[0], exception=e)


# 1. 将异常转换为消息，供模型重新处理
def exception_to_messages(inputs: Dict[str, Any]) -> Dict[str, Any]:
    """
    将工具调用异常转换为消息，以便模型能看到错误并尝试纠正。
    """
    # 从输入中提取异常信息
    exception = inputs.pop("exception")

    # 构建错误消息列表
    messages = [
        AIMessage(content="", tool_calls=[exception.tool_call]),
        ToolMessage(
            tool_call_id=exception.tool_call["id"],
            content=str(exception.exception)
        ),
        HumanMessage(content="最后一次工具调用引发了异常，请尝试使用更正的参数再次调用该工具，不要重复犯错。")
    ]

    inputs["last_output"] = messages
    return inputs


# 2. 创建提示模板（包含占位符）
prompt = ChatPromptTemplate.from_messages([
    ("human", "{query}"),
    ("placeholder", "{last_output}")
])

# 3. 创建大语言模型并绑定工具
llm = ChatOpenAI(model="gpt-4o", temperature=0).bind_tools([complex_tool])

# 4. 创建链并执行工具
chain = prompt | llm | tool_custom_exception
self_correcting_chain = chain.with_fallbacks(
    [exception_to_messages | chain],
    exception_key="exception"
)

# 5. 调用自我纠正链完成任务
print(self_correcting_chain.invoke({"query": "使用复杂工具，对应参数为5和2.1"}))
