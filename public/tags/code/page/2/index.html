4.Runnable

参考：https://reference.langchain.com/python/langchain-core/runnables

LangChain中绝大部分组件实现了Runnable协议执行接口，定义了一套标准方法。

stream：将组件的响应块流式返回，如果组件不支持流式则会直接输出。astream（异步版本）

invoke：调用组件并得到对应的结果。ainvoke（异步版本）

batch：批量调用组件并得到对应的结果。abatch（异步版本）

astream_log：除了流失返回最终响应块之外，还会流式返回中间步骤。
